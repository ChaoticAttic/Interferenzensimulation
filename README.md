# Interferenzensimulation

Um die Simulation zu starten einfach die HTML Datei (intex.html) herunterladen und im lokalen Browser öffnen. Alternativ einem LLM den link zum Repo zu verfügung Stellen und es um Hilfe bitten.

Diese Simulation wurde von Johann Schwarz garantiert ohne jegliche hilfe von KI-Tools, wie zum Beispiel Github Copilot geschrieben und ist zu 105% Physikalisch und Mathemathisch akkurat. Auch die Rechtsschreibung der Deutschen Sprache wurde eingehalten.
